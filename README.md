# AWS 3-Tier Web Application

A production-style AWS 3-Tier Web Application built using Amazon VPC, EC2, Nginx, Security Groups, Route Tables, Internet Gateway, and NAT Gateway.

## Technologies Used

- Amazon VPC
- Amazon EC2
- Nginx
- Amazon Linux 2023
- Security Groups
- Internet Gateway
- NAT Gateway
- Route Tables
- Linux
- Git & GitHub

## Project Status

- ✅ Phase 1 – VPC Setup
- ✅ Phase 2 – Networking Setup
- ✅ Phase 3 – EC2 & Nginx Deployment
- ✅ Phase 4 – Frontend Deployment

More features such as Application Load Balancer, Auto Scaling, RDS, CloudWatch, and GitHub Actions CI/CD will be added in future phases.
